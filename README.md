# Impotech AI Messenger Bot

Impotech Facebook Messenger AI Customer Support Bot.

## Features

- Facebook Messenger Webhook
- AI Text Reply
- Image / Vision Support
- Voice Message Support
- OpenRouter AI
- Google Gemini
- GitHub Product Catalog
- Product Matching
- FAQ Matching
- Customer Conversation History
- Order Detection
- Phone Number Detection
- Address Detection
- Global Human Takeover
- Personal Customer Human Takeover
- PostgreSQL Persistent State
- Android Admin API
- Render Restart State Recovery
- Automatic Data Retention
